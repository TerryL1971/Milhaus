# Demo Special Offers ads

The three demo ads on the homepage's Special Offers row (2026-11-04),
designed as HTML so they're easy to change: Ramstein Moving Co.,
Schwarzwald Auto Detailing and Kaiserslautern Family Dental. All
original artwork (no photos), so there are no image rights to track.

To re-render one: open the .html file in Chrome at 500×600 with a device
scale of 2 and screenshot it (1000×1200), then upload it in
Admin → Ad slots → Edit under a new file name. The layout keeps
everything important in the middle 368px, because a desktop card is
narrower than the design and the sides get cropped.

These are demo content: remove or replace them with real advertisers'
artwork before launch.
